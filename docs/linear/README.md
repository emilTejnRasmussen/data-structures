# Linear Data Structures

Linear data structures organize elements in a sequence.

## Topics

| Structure | Main idea |
|---|---|
| [Lists](lists.md) | Ordered collection with position-based access |
| [Stacks](stacks.md) | Last In, First Out |
| [Queues](queues.md) | First In, First Out |

## Implementations

The project contains both array-backed and linked implementations where useful.

This makes it possible to compare how the same abstract data structure behaves with different internal representations.
